# 🐍 OOP Concepts in One File - Python

Welcome to this all-in-one Python script demonstrating Object-Oriented Programming (OOP) core pillars! 

---

## 📚 Concepts Covered in this File

1. **Class & Object:** Creating a blueprint (`Person`) and instantiating an object (`p1`).
2. **Inheritance:** Deriving child classes (`Dog`, `Cat`) from a parent class (`Animal`) to reuse code.
3. **Polymorphism:** Using a single function (`show_movement`) to handle different types of objects (`Bird`, `Fish`) that share the same method name.
4. **Encapsulation:** Restricting direct access to data using private variables (`__balance`) and controlling access via getter/setter methods.
5. **Abstraction:** Hiding complex implementation details using abstract base classes (`ABC` and `@abstractmethod`) with `Vehicle`, `Car`, and `Bike`.
